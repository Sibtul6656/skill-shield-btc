# Skill Shield Alpha

AI-Powered Institutional Analytics Engine — Flask dashboard.

## Stack

- **Language:** Python 3.11
- **Web framework:** Flask
- **HTTP client:** requests
- **Port:** 5000 (host 0.0.0.0)

## Layout

```
main.py             # Flask app: dashboard + blockchain.info stats
requirements.txt    # Python dependencies (flask, requests)
```

## Run

The `Start application` workflow runs:

```
python main.py
```
